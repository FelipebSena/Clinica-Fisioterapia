## Estrutura do projeto

### docs/
Contém os documentos e modelos desenvolvidos durante a Etapa 1.

### sql/
Contém os scripts SQL utilizados para implementação e consulta do banco de dados.

## Scripts SQL

Os scripts devem ser executados na seguinte ordem:

1. `01_ddl.sql` — criação da estrutura do banco de dados.
2. `02_carga.sql` — inserção dos dados.
3. `03_consultas.sql` — consultas do banco de dados.
